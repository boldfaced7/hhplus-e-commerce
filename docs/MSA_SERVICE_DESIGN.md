# MSA 서비스 설계 문서

## 1. 개요

### 1.1 목적
현재 모놀리식 아키텍처로 구현된 이커머스 시스템을 MSA로 전환하여 서비스의 확장성과 유지보수성을 향상시키고, 각 도메인별 독립적인 배포와 운영이 가능하도록 설계합니다.

### 1.2 현재 시스템 분석
현재 시스템은 다음과 같은 도메인으로 구성되어 있습니다:
- **Order Domain**: 주문 생성 및 관리
- **Product Domain**: 상품 정보 및 재고 관리
- **Balance Domain**: 사용자 잔액 관리
- **Coupon Domain**: 쿠폰 발급 및 사용 관리

## 2. MSA 도메인 분리 설계

### 2.1 서비스 분리 전략

#### 2.1.1 Order Service (주문 서비스)
**책임**: 주문 생성, 주문 상태 관리, 주문 조회
- **핵심 기능**:
  - 주문 생성 및 저장
  - 주문 상태 관리 (생성 → 진행중 → 완료/실패)
  - 주문 조회 및 이력 관리
- **데이터**: `Order`, `OrderItem` 엔티티

#### 2.1.2 Product Service (상품 서비스)
**책임**: 상품 정보 관리, 재고 관리, 인기 상품 조회
- **핵심 기능**:
  - 상품 정보 CRUD
  - 재고 관리 (차감, 복구)
  - 인기 상품 조회 (Redis 기반)
- **데이터**: `Product` 엔티티

#### 2.1.3 Balance Service (잔액 서비스)
**책임**: 사용자 잔액 관리, 충전, 차감
- **핵심 기능**:
  - 잔액 충전
  - 잔액 차감 (주문 시)
  - 잔액 복구 (주문 실패 시)
- **데이터**: `Balance` 엔티티

#### 2.1.4 Coupon Service (쿠폰 서비스)
**책임**: 쿠폰 발급, 사용, 취소 관리
- **핵심 기능**:
  - 쿠폰 발급
  - 쿠폰 사용 처리
  - 쿠폰 사용 취소
- **데이터**: `Coupon` 엔티티

### 2.2 서비스 간 통신 방식

#### 2.2.1 동기 통신 (REST API)
- **용도**: 즉시 응답이 필요한 요청
- **예시**: 
  - 주문 생성 시 상품 정보 조회
  - 주문 생성 시 사용자 정보 조회

#### 2.2.2 비동기 통신 (Event-Driven)
- **용도**: 데이터 일관성 보장을 위한 이벤트 기반 통신
- **예시**: 
  - 주문 생성 이벤트
  - 재고 차감 이벤트
  - 잔액 차감 이벤트

## 3. 트랜잭션 처리 한계와 해결방안

### 3.1 분산 트랜잭션의 한계

#### 3.1.1 문제점
- **2PC(2-Phase Commit)의 한계**: 성능 저하, 가용성 문제
- **데이터 일관성**: 서비스 간 데이터 불일치 가능성
- **장애 전파**: 한 서비스의 장애가 다른 서비스에 영향

#### 3.1.2 현재 구현된 해결방안

### 3.2 Saga 패턴을 통한 해결

#### 3.2.1 Orchestration Saga 패턴
현재 시스템에서 구현된 `PlaceOrderSagaOrchestrator`를 기반으로 한 분산 트랜잭션 처리:

```java
// 주문 생성 → 쿠폰 사용 → 잔액 차감 → 재고 차감 → 주문 완료
OrderCreated → CouponUsed → BalanceDeducted → StockDeducted → OrderCompleted
```

#### 3.2.2 보상 트랜잭션 (Compensating Transaction)
각 단계별 실패 시 이전 단계를 되돌리는 보상 트랜잭션 구현:

1. **쿠폰 사용 실패**: 주문 실패 처리
2. **잔액 차감 실패**: 쿠폰 사용 취소 → 주문 실패
3. **재고 차감 실패**: 잔액 차감 취소 → 쿠폰 사용 취소 → 주문 실패

### 3.3 이벤트 기반 아키텍처

#### 3.3.1 이벤트 스토어
- **Redis 기반 컨텍스트 저장**: `PlaceOrderSagaContext`
- **이벤트 발행**: 각 단계별 도메인 이벤트 발행
- **이벤트 구독**: 다른 서비스에서 이벤트 구독하여 처리

#### 3.3.2 이벤트 종류
```java
// 주문 도메인 이벤트
OrderCreated, OrderCompleted, OrderFailed

// 상품 도메인 이벤트  
StockDeducted, StockDeductionFailed

// 잔액 도메인 이벤트
BalanceDeducted, BalanceDeductionFailed, BalanceDeductionCancelled

// 쿠폰 도메인 이벤트
CouponUsed, CouponUseFailed, CouponUseCancelled
```
